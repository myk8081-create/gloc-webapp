G
GLOC 재고관리 사용 매뉴얼

START

처음 사용하는 분은 여기부터 보세요

이 매뉴얼은 개발 지식 없이 GLOC 재고관리 웹앱을 운영하는 사람을 위한 클릭형 안내서입니다. 왼쪽 목차 또는 아래 다음 버튼을 눌러 단계별로 진행하면 됩니다.

웹앱에서 할 수 있는 일

관리자

본사 운영

대리점 계정 생성, 제품 등록, 본사 재고 수정, 전체 재고 조회, 발주 상태 변경, QR/안내문 생성을 할 수 있습니다.

대리점/샵

현장 운영

내 재고 조회/수정, 본사 재고 조회, 전체 대리점/샵 재고 조회, 발주 신청, 내 발주 내역 확인을 할 수 있습니다.

중요

관리자는 모든 정보를 볼 수 있습니다. 대리점/샵은 발주와 재고 수정은 본인 계정 기준으로만 할 수 있습니다.

LOGIN

로그인하기

QR 또는 카카오톡 링크로 접속하면 로그인 화면이 나옵니다.

1

웹앱 주소 또는 QR로 접속

휴대폰 카메라로 QR을 스캔하거나, 카카오톡으로 받은 링크를 누릅니다.

QR 스캔 또는 링크 클릭
2

로그인 유형 선택

본사 담당자는 관리자, 대리점/샵은 대리점을 선택합니다.

대리점 또는 관리자 클릭
3

아이디, 비밀번호, 대리점 코드 입력

관리자는 대리점 코드에 ADMIN을 입력합니다. 대리점/샵은 안내받은 대리점 코드를 입력합니다.

아이디 입력 → 비밀번호 입력 → 대리점 코드 입력
4

로그인 후 이동

입력이 끝나면 로그인 후 이동 버튼을 누릅니다.

로그인 후 이동 클릭

최초 로그인 화면이 나오면

초기 비밀번호로 처음 로그인한 계정은 새 비밀번호 변경 화면으로 이동합니다. 새 비밀번호는 8자 이상으로 입력하세요.

ADMIN SETUP

관리자가 처음 해야 할 일

처음에는 관리자 비밀번호 변경, 제품 등록, 대리점 계정 생성, 공통 QR 전달 순서로 진행하면 됩니다.

1

관리자 비밀번호 변경

초기 비밀번호로 로그인하면 비밀번호 변경 화면이 나옵니다. 회사에서 사용할 새 비밀번호로 바꿉니다.

현재 비밀번호 입력 → 새 비밀번호 입력 → 비밀번호 변경 후 시작 클릭
2

제품 등록

판매할 PPF/틴팅 제품을 먼저 등록합니다. 제품이 등록되어야 재고와 발주에서 선택할 수 있습니다.

제품 메뉴 클릭 → SKU/제품명/카테고리 입력 → 제품 저장 클릭
3

대리점 계정 생성

각 대리점/샵이 로그인할 계정을 만듭니다.

대리점 메뉴 클릭 → 대리점 코드/대리점명/아이디/초기 비밀번호 입력 → 대리점 계정 생성 클릭
4

QR과 카카오톡 안내문 전달

모든 대리점은 같은 QR과 같은 링크를 사용합니다. 로그인 정보만 대리점별로 다르게 전달합니다.

QR 메뉴 클릭 → QR 다운로드 또는 안내문 복사 클릭

ACCOUNT

대리점 계정 만들기와 관리

대리점/샵이 앱을 사용하려면 관리자 화면에서 계정을 먼저 만들어야 합니다.

새 계정 만들기

1

대리점 메뉴로 이동

관리자 로그인 후 하단 또는 화면의 대리점 메뉴를 누릅니다.

대리점 클릭
2

계정 정보 입력

대리점 코드, 대리점명, 아이디, 초기 비밀번호를 입력합니다.

D001 → 서울 총판 → dealer01 → 임시 비밀번호 입력
3

계정 생성

대리점 계정 생성 버튼을 누르면 계정이 만들어집니다.

대리점 계정 생성 클릭

비밀번호 초기화

대리점이 비밀번호를 잊었을 때 사용합니다. 기존 비밀번호는 확인할 수 없고, 새 임시 비밀번호를 발급해야 합니다.

1

계정 목록에서 찾기

초기화할 대리점 계정 오른쪽의 PW 초기화를 누릅니다.

대리점 메뉴 → PW 초기화 클릭
2

새 임시 비밀번호 입력

입력한 임시 비밀번호를 대리점에 전달합니다. 대리점은 다음 로그인 시 새 비밀번호로 변경합니다.

임시 비밀번호 입력 → 확인

계정삭제 주의

계정삭제를 누르면 해당 대리점 계정과 해당 대리점의 재고 행이 삭제됩니다. 기존 발주 이력은 남습니다.

PRODUCT

제품 등록, 수정, 삭제

제품은 관리자만 등록/수정/삭제할 수 있습니다. 제품을 먼저 등록해야 재고와 발주에서 사용할 수 있습니다.

1

제품 메뉴 열기

관리자 로그인 후 제품 메뉴를 누릅니다.

제품 클릭
2

제품 정보 입력

SKU, 제품명, 카테고리, 단위, 판매 여부를 입력합니다.

SKU 입력 → 제품명 입력 → 카테고리 선택 → 제품 저장 클릭
3

기존 제품 수정

제품 목록에서 수정할 제품을 선택한 뒤 내용을 바꾸고 제품 저장을 누릅니다.

제품 목록에서 제품 클릭 → 내용 수정 → 제품 저장 클릭
4

제품 삭제

제품 목록에서 삭제를 누르면 해당 SKU 제품과 재고 행이 삭제됩니다.

삭제 클릭 → 확인

SKU는 제품의 고유번호입니다

같은 SKU를 다시 저장하면 새 제품이 생기는 것이 아니라 기존 제품 정보가 수정됩니다.

INVENTORY

재고 조회하기

재고 화면에서는 본사 재고, 내 대리점/샵 재고, 전체 대리점/샵 재고를 나누어 볼 수 있습니다.

로그인 유형 보이는 탭 의미
관리자 본사 재고, 전체 대리점/샵 재고 관리자는 본사 재고와 모든 대리점/샵 재고를 조회할 수 있습니다.
대리점/샵 내 대리점/샵 재고, 본사 재고, 전체 대리점/샵 재고 대리점은 전체를 볼 수 있지만 수정과 발주는 본인 계정 기준으로 처리됩니다.
1

재고 메뉴 열기

로그인 후 하단 메뉴의 재고를 누릅니다.

재고 클릭
2

조회 범위 선택

상단의 탭에서 보고 싶은 범위를 선택합니다.

본사 재고 또는 전체 대리점/샵 재고 클릭
3

검색어 입력

제품명, SKU, 대리점명, 재고수량으로 검색할 수 있습니다.

검색창 클릭 → 검색어 입력

안전재고 이하 표시

현재 재고가 안전재고보다 적거나 같으면 강조 표시됩니다. 발주 또는 재고 보충이 필요한 제품입니다.

EDIT STOCK

재고 수정하기

관리자는 본사 재고를 수정하고, 대리점/샵은 본인 재고만 수정합니다.

1

재고수정 화면 열기

관리자는 대시보드의 재고 수정 버튼 또는 메뉴를 누릅니다. 대리점/샵은 하단의 재고수정을 누릅니다.

재고수정 클릭
2

수정할 제품 선택

왼쪽 목록에서 제품을 누릅니다. 검색창에 제품명이나 SKU를 입력해 찾을 수 있습니다.

제품 검색 → 제품 클릭
3

수량과 위치 입력

현재 재고, 안전재고, 보관 위치를 입력합니다.

현재 재고 입력 → 안전재고 입력 → 위치 입력
4

저장

재고 저장 버튼을 누르면 변경 내용이 저장됩니다.

재고 저장 클릭

재고 수정 권한

대리점/샵은 다른 대리점 재고를 볼 수는 있어도 수정할 수 없습니다. 수정은 본인 대리점/샵 재고만 가능합니다.

ORDER

대리점/샵에서 발주 신청하기

발주신청은 대리점/샵 계정에서 사용합니다. 등록된 발주는 기본 상태가 접수입니다.

1

발주신청 열기

하단 메뉴의 발주신청을 누릅니다.

발주신청 클릭
2

제품 선택

제품 목록에서 발주할 제품을 선택합니다. 제품명, SKU, 컬러로 검색할 수 있습니다.

제품 검색 → 제품 클릭
3

수량과 메모 입력

발주 수량을 1개 이상 입력합니다. 배송 요청사항이 있으면 메모에 적습니다.

발주 수량 입력 → 메모 입력
4

발주 등록

발주 등록을 누르면 본사 관리자에게 접수됩니다.

발주 등록 클릭

ORDER STATUS

발주 확인과 상태 변경

관리자는 전체 발주 상태를 변경할 수 있고, 대리점/샵은 본인 발주 내역만 확인합니다.

1

발주 화면 열기

관리자는 발주 메뉴를 누릅니다. 대리점/샵은 내 발주 메뉴를 누릅니다.

발주 또는 내 발주 클릭
2

발주 검색

주문번호, 제품명, SKU, 대리점명으로 발주 내역을 찾습니다.

검색창 클릭 → 검색어 입력
3

상태 변경

관리자는 발주 카드의 상태를 접수, 승인, 출고, 완료, 반려 중 하나로 변경할 수 있습니다.

상태 선택 → 변경 확인
상태 의미 사용 예시
접수 대리점이 발주를 넣은 상태 관리자가 아직 확인 전
승인 본사에서 발주를 확인하고 승인한 상태 출고 준비 시작
출고 제품이 출고된 상태 배송 또는 전달 중
완료 발주 처리가 끝난 상태 대리점 수령 완료
반려 발주를 처리하지 않는 상태 재고 부족, 정보 오류 등

QR

QR과 카카오톡 안내문 보내기

현재 구조는 대리점별 QR이 아니라 모든 대리점이 같은 QR과 같은 링크를 사용합니다.

1

QR 메뉴 열기

관리자 로그인 후 QR 메뉴를 누릅니다.

QR 클릭
2

공통 QR 다운로드

QR 다운로드 버튼을 눌러 공통 접속 QR 이미지를 저장합니다.

QR 다운로드 클릭
3

안내문 복사

대리점별 안내문에서 안내문 복사를 누른 뒤 카카오톡에 붙여넣습니다.

안내문 복사 클릭 → 카카오톡 붙여넣기

안내문에 들어가는 정보

접속 링크, 초기 ID, 초기 PW, 대리점 코드가 포함됩니다. 초기 PW가 기억나지 않으면 먼저 대리점 메뉴에서 PW 초기화를 해야 합니다.

MOBILE

휴대폰에서 사용하는 방법

대리점/샵은 대부분 휴대폰에서 QR 또는 카카오톡 링크로 접속하게 됩니다.

1

QR 스캔

휴대폰 카메라를 열고 QR을 비춥니다. 화면에 뜨는 링크를 누릅니다.

카메라 실행 → QR 스캔 → 링크 클릭
2

로그인 정보 입력

카카오톡 안내문에 있는 아이디, 비밀번호, 대리점 코드를 입력합니다.

아이디 → 비밀번호 → 대리점 코드 → 로그인 후 이동
3

하단 메뉴 사용

휴대폰에서는 화면 아래쪽 메뉴를 눌러 재고, 재고수정, 발주신청, 내 발주로 이동합니다.

하단 메뉴 클릭

화면 아래가 가려질 때

휴대폰 브라우저에서 주소창이나 하단바가 겹치면 화면을 살짝 위로 스크롤한 뒤 버튼을 누릅니다.

SHORTCUT

휴대폰 홈화면에 바로가기 만들기

홈화면에 GLOC 바로가기를 만들면 웹앱을 일반 앱처럼 빠르게 열 수 있습니다.

아이폰 Safari

1

Safari로 사이트 열기

아이폰에서 Safari를 열고 GLOC 운영 사이트 또는 카카오톡으로 받은 링크에 접속합니다.

Safari → GLOC 링크 열기
2

공유 버튼 누르기

화면 아래쪽의 공유 버튼을 누릅니다.

공유 버튼 클릭
3

홈 화면에 추가

홈 화면에 추가를 선택하고 이름을 확인한 뒤 추가를 누릅니다.

홈 화면에 추가 → 추가

안드로이드 Chrome

1

Chrome으로 사이트 열기

안드로이드에서 Chrome을 열고 GLOC 운영 사이트 또는 카카오톡으로 받은 링크에 접속합니다.

Chrome → GLOC 링크 열기
2

더보기 메뉴 열기

오른쪽 위 점 3개 메뉴를 누릅니다.

점 3개 메뉴 클릭
3

홈 화면에 추가

홈 화면에 추가 또는 앱 설치를 선택하고 추가를 누릅니다.

홈 화면에 추가 또는 앱 설치 → 추가

아이콘이 바로 안 바뀔 때

예전에 만든 바로가기는 이전 아이콘이 남을 수 있습니다. 기존 바로가기를 삭제한 뒤 다시 추가하면 새 GLOC 아이콘으로 보입니다.

HELP

자주 생기는 문제 해결

현장에서 가장 자주 나오는 질문만 모았습니다.

문제 확인할 것 처리 방법
비밀번호가 일치하지 않는다고 나옴 아이디, 비밀번호, 대리점 코드가 모두 맞는지 확인 계속 안 되면 관리자가 PW 초기화를 진행
대리점 코드 오류 관리자는 `ADMIN`, 대리점은 안내받은 코드인지 확인 대소문자와 숫자를 다시 확인
제품이 발주 화면에 없음 제품이 등록되어 있고 판매중인지 확인 관리자 → 제품 메뉴에서 제품 저장
재고 수정이 안 됨 수정 권한이 있는 재고인지 확인 관리자는 본사 재고, 대리점은 본인 재고만 수정 가능

SITE TROUBLE

사이트에 문제가 생겼을 때

비개발자는 원인을 고치기보다, 먼저 문제가 개인 기기 문제인지 전체 장애인지 구분하고 필요한 정보를 정확히 모으는 것이 중요합니다.

가장 중요한 원칙

저장이 안 되거나 화면이 이상할 때 같은 작업을 여러 번 반복하지 마세요. 같은 발주가 중복 등록되거나 재고가 잘못 저장될 수 있습니다.

5분 안에 먼저 확인할 것

1

새로고침

화면이 멈췄거나 버튼 반응이 없으면 브라우저 새로고침을 한 번만 합니다.

새로고침 → 다시 로그인 또는 같은 화면 확인
2

다른 인터넷으로 접속

회사 와이파이에서 안 되면 휴대폰 데이터로, 휴대폰 데이터에서 안 되면 와이파이로 접속해 봅니다.

와이파이 끄기/켜기 → 사이트 다시 접속
3

다른 기기에서 확인

본인 휴대폰에서만 안 되는지, 다른 직원 휴대폰이나 PC에서도 안 되는지 확인합니다.

다른 휴대폰 또는 PC에서 같은 주소 접속
4

문제 범위 구분

한 사람만 안 되면 계정/기기 문제일 가능성이 높고, 모두 안 되면 사이트 또는 데이터 연결 문제일 가능성이 높습니다.

나만 문제인지 / 전체 문제인지 확인

증상별 조치

증상 비개발자가 할 일 다음 조치
사이트가 아예 안 열림 다른 인터넷, 다른 기기, 다른 브라우저에서 접속 확인 모두 안 되면 관리자에게 운영 사이트 장애로 전달
로그인만 안 됨 아이디, 비밀번호, 대리점 코드를 다시 확인 계속 실패하면 관리자에게 PW 초기화 요청
저장 버튼을 눌러도 반응 없음 한 번만 새로고침 후 다시 시도. 계속 안 되면 반복 저장 금지 입력한 내용과 화면 캡처를 관리자에게 전달
재고 숫자가 이상함 언제, 어떤 제품, 기존 수량, 입력 수량을 적어둠 관리자가 재고수정 화면 또는 원본 데이터 확인
발주가 중복됨 중복 주문번호와 제품명을 관리자에게 전달 관리자가 발주 상태를 반려 또는 별도 처리
샘플 모드라고 보임 사용자는 추가 작업을 멈추고 관리자에게 화면 캡처 전달 기술 담당자가 운영 환경변수와 Apps Script URL 확인
