GLOC 대리점/샵 매뉴얼

DEALER

대리점/샵 사용 매뉴얼

대리점과 시공샵이 휴대폰 또는 PC에서 재고를 확인하고, 내 재고를 수정하고, 본사로 발주를 신청하는 방법을 안내합니다.

대리점/샵에서 할 수 있는 일

내 재고 조회/수정, 본사 재고 조회, 전체 대리점/샵 재고 조회, 발주 신청, 내 발주 상태 확인을 할 수 있습니다.

중요

대리점/샵은 다른 지점 재고를 볼 수 있지만, 재고 수정과 발주 등록은 본인 계정 기준으로만 처리됩니다.

LOGIN

QR 또는 링크로 로그인

대리점/샵은 공통 QR 또는 카카오톡 링크로 접속한 뒤 안내받은 로그인 정보를 입력합니다.

1

QR 스캔 또는 링크 클릭

휴대폰 카메라로 QR을 스캔하거나 카카오톡으로 받은 링크를 누릅니다.

QR 스캔 또는 링크 클릭
2

대리점 선택

로그인 화면에서 대리점을 선택합니다.

대리점 클릭
3

로그인 정보 입력

안내받은 아이디, 비밀번호, 대리점 코드를 입력합니다.

아이디 → 비밀번호 → 대리점 코드 입력
4

로그인

로그인 후 이동 버튼을 누릅니다.

로그인 후 이동 클릭

PASSWORD

최초 로그인 비밀번호 변경

초기 비밀번호로 처음 로그인하면 새 비밀번호로 변경해야 합니다.

1

현재 비밀번호 입력

카카오톡 안내문으로 받은 초기 비밀번호를 입력합니다.

현재 비밀번호 입력
2

새 비밀번호 입력

앞으로 사용할 새 비밀번호를 8자 이상으로 입력합니다.

새 비밀번호 → 새 비밀번호 확인
3

변경 완료

비밀번호 변경 후 시작을 누릅니다.

비밀번호 변경 후 시작 클릭

비밀번호를 잊었을 때

본사 관리자에게 비밀번호 초기화를 요청하세요. 기존 비밀번호는 확인할 수 없고 새 임시 비밀번호를 발급받아야 합니다.

STOCK VIEW

재고 조회하기

대리점/샵은 내 재고, 본사 재고, 전체 대리점/샵 재고를 나누어 볼 수 있습니다.

1

재고 메뉴 열기

하단 메뉴에서 재고를 누릅니다.

재고 클릭
2

조회 범위 선택

내 대리점/샵 재고, 본사 재고, 전체 대리점/샵 재고 중 하나를 선택합니다.

내 재고 / 본사 재고 / 전체 재고 클릭
3

검색

제품명, SKU, 대리점명, 재고수량으로 검색합니다.

검색창 클릭 → 검색어 입력
탭 의미
내 대리점/샵 재고 본인 지점의 재고입니다. 수정할 수 있습니다.
본사 재고 본사에서 보유 중인 재고입니다. 조회만 가능합니다.
전체 대리점/샵 재고 다른 지점 재고까지 한눈에 볼 수 있습니다. 조회만 가능합니다.

STOCK EDIT

내 대리점/샵 재고 수정

대리점/샵은 본인 지점 재고만 직접 수정할 수 있습니다.

1

재고수정 열기

하단 메뉴에서 재고수정을 누릅니다.

재고수정 클릭
2

제품 선택

수정할 제품을 검색하고 선택합니다.

제품 검색 → 제품 클릭
3

재고 입력

현재 재고, 안전재고, 보관 위치를 입력합니다.

현재 재고 → 안전재고 → 위치 입력
4

저장

재고 저장 버튼을 누릅니다.

재고 저장 클릭

주의

다른 대리점 재고나 본사 재고는 조회만 가능하고 수정할 수 없습니다.

ORDER

발주 신청하기

필요한 제품과 수량을 입력하면 본사로 발주가 접수됩니다.

1

발주신청 열기

하단 메뉴에서 발주신청을 누릅니다.

발주신청 클릭
2

제품 선택

발주할 제품을 검색하고 선택합니다.

제품 검색 → 제품 클릭
3

수량과 메모 입력

발주 수량을 입력하고 필요하면 배송 요청사항을 메모에 적습니다.

발주 수량 입력 → 메모 입력
4

발주 등록

발주 등록을 누릅니다. 기본 상태는 접수입니다.

발주 등록 클릭

중복 발주 주의

버튼 반응이 늦어도 여러 번 누르지 마세요. 같은 발주가 중복 등록될 수 있습니다.

MY ORDERS

내 발주 상태 확인

본인이 등록한 발주 내역과 처리 상태를 확인합니다.

1

내 발주 열기

내 발주 클릭
2

발주 검색

주문번호, 제품명, SKU로 발주를 찾습니다.

MOBILE

휴대폰에서 사용할 때

대리점/샵은 휴대폰으로 사용하는 경우가 많으므로 아래 내용을 참고하세요.

1

QR은 카메라로 스캔

카메라 앱으로 QR을 비추고 화면에 뜨는 링크를 누릅니다.

카메라 실행 → QR 스캔 → 링크 클릭
2

하단 메뉴 사용

휴대폰 화면 아래의 재고, 재고수정, 발주신청, 내 발주 메뉴를 사용합니다.

하단 메뉴 클릭
3

버튼이 가려질 때

브라우저 주소창이나 하단바가 겹치면 화면을 살짝 위로 스크롤합니다.

화면 위로 스크롤

HELP

문제가 생겼을 때

대부분의 문제는 로그인 정보 확인, 새로고침, 본사 문의로 해결할 수 있습니다.

문제 먼저 확인할 것 해결 방법
로그인이 안 됨 아이디, 비밀번호, 대리점 코드 확인 계속 안 되면 본사에 PW 초기화 요청
재고 저장이 안 됨 한 번만 새로고침 후 다시 시도 계속 안 되면 화면 캡처 후 본사 전달
발주 버튼 반응이 없음 반복 클릭 금지 내 발주에 등록됐는지 확인 후 본사 문의
제품이 없음 검색어가 정확한지 확인 제품 등록 여부를 본사에 문의
재고 숫자가 이상함 어떤 제품인지, 어떤 수량인지 기록 제품명/SKU/수량을 본사에 전달

REPORT

본사에 문의할 때 보내야 할 정보

문제가 생겼을 때 아래 정보를 같이 보내면 빠르게 확인할 수 있습니다.

1

문제 발생 시간

예: 2026년 5월 14일 오후 3시 20분

2

계정과 대리점 코드

예: dealer01 / D001

3

문제가 생긴 메뉴

예: 재고수정, 발주신청, 내 발주

4

화면 캡처

오류 문구가 보이도록 화면을 캡처해서 보냅니다.

문의 예시

dealer01 / D001 계정입니다. 재고수정에서 TN-CR-094 제품을 10롤로 저장했는데 저장 완료 메시지가 나오지 않습니다. 오후 3시 20분에 발생했고 화면 캡처 첨부합니다.

SHORTCUT

휴대폰 홈화면에 바로가기 만들기

홈화면에 바로가기를 만들면 QR을 다시 찾지 않아도 앱처럼 바로 접속할 수 있습니다.

아이폰 Safari

1

Safari로 사이트 열기

아이폰에서 Safari를 열고 카카오톡으로 받은 GLOC 링크를 엽니다.

Safari → GLOC 링크 열기
2

공유 버튼 누르기

화면 아래쪽의 공유 버튼을 누릅니다.

공유 버튼 클릭
3

홈 화면에 추가

홈 화면에 추가를 선택하고 이름을 확인한 뒤 추가를 누릅니다.

홈 화면에 추가 → 추가

안드로이드 Chrome

1

Chrome으로 사이트 열기

안드로이드에서 Chrome을 열고 카카오톡으로 받은 GLOC 링크를 엽니다.

Chrome → GLOC 링크 열기
2

더보기 메뉴 열기

오른쪽 위 점 3개 메뉴를 누릅니다.

점 3개 메뉴 클릭
3

홈 화면에 추가

홈 화면에 추가 또는 앱 설치를 선택하고 추가를 누릅니다.

홈 화면에 추가 또는 앱 설치 → 추가

아이콘이 바로 안 바뀔 때

예전에 만든 바로가기는 이전 아이콘이 남을 수 있습니다. 기존 바로가기를 삭제한 뒤 다시 추가하면 새 GLOC 아이콘으로 보입니다.
