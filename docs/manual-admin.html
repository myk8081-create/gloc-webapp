GLOC 본사 관리자 매뉴얼

HEAD OFFICE

본사 관리자용 매뉴얼

본사 담당자가 대리점 계정, 제품, 본사 재고, 전체 재고, 발주 상태, QR 안내문을 관리하기 위한 매뉴얼입니다.

본사에서 관리하는 항목

대리점 계정 생성/초기화/삭제, 제품 등록/수정/삭제, 본사 재고 수정, 전체 대리점/샵 재고 조회, 발주 상태 변경, 공통 QR 및 안내문 전달을 처리합니다.

중요

본사는 전체 데이터를 볼 수 있지만, 대리점/샵이 직접 관리해야 하는 재고는 현장 입력 기준으로 운영하는 것이 좋습니다.

LOGIN

관리자 로그인

본사 담당자는 로그인 화면에서 관리자 유형을 선택하고 접속합니다.

1

웹앱 주소 접속

운영 사이트 주소 또는 공통 QR 링크로 접속합니다.

운영 사이트 접속
2

관리자 선택

로그인 화면에서 관리자 버튼을 선택합니다.

관리자 클릭
3

로그인 정보 입력

관리자 아이디, 비밀번호, 대리점 코드 ADMIN을 입력합니다.

아이디 → 비밀번호 → ADMIN 입력
4

로그인

로그인 후 이동을 누릅니다.

로그인 후 이동 클릭

SETUP

처음 세팅 순서

처음 운영을 시작할 때는 비밀번호 변경, 제품 등록, 대리점 계정 생성, QR 안내 순서로 진행합니다.

1

관리자 비밀번호 변경

초기 비밀번호로 로그인했다면 새 비밀번호로 변경합니다.

현재 비밀번호 입력 → 새 비밀번호 입력 → 비밀번호 변경 후 시작
2

제품 등록

판매할 PPF/틴팅 제품을 등록합니다.

제품 클릭 → SKU/제품명/카테고리 입력 → 제품 저장
3

대리점 계정 생성

대리점/샵별 로그인 계정을 만듭니다.

대리점 클릭 → 계정 정보 입력 → 대리점 계정 생성
4

QR과 안내문 전달

공통 QR과 대리점별 로그인 안내문을 전달합니다.

QR 클릭 → QR 다운로드 또는 안내문 복사

ACCOUNT

대리점 계정 관리

대리점/샵이 웹앱을 사용하려면 본사에서 계정을 만들어야 합니다.

새 계정 만들기

1

대리점 메뉴 열기

관리자 화면에서 대리점 메뉴를 누릅니다.

대리점 클릭
2

계정 정보 입력

대리점 코드, 대리점명, 아이디, 초기 비밀번호를 입력합니다.

D001 → 서울 총판 → dealer01 → 임시 비밀번호
3

계정 생성

대리점 계정 생성 버튼을 누릅니다.

대리점 계정 생성 클릭

비밀번호 초기화와 계정삭제

기능 사용 상황 처리 방법
PW 초기화 대리점이 비밀번호를 잊었을 때 대리점 메뉴 → PW 초기화 → 새 임시 비밀번호 입력
사용중지 거래 중지 또는 임시 차단이 필요할 때 대리점 메뉴 → 사용중지 클릭
계정삭제 더 이상 사용하지 않는 계정을 완전히 제거할 때 대리점 메뉴 → 계정삭제 클릭 → 확인

계정삭제 주의

계정을 삭제하면 해당 대리점 계정과 재고 행이 삭제됩니다. 기존 발주 이력은 보존됩니다.

PRODUCT

제품 등록, 수정, 삭제

제품은 본사 관리자만 등록/수정/삭제할 수 있습니다.

1

제품 메뉴 열기

하단 또는 대시보드에서 제품 메뉴를 누릅니다.

제품 클릭
2

제품 정보 입력

SKU, 제품명, 카테고리, 단위, 판매 여부를 입력합니다.

SKU 입력 → 제품명 입력 → 카테고리 선택
3

저장

제품 저장 버튼을 누릅니다.

제품 저장 클릭
4

수정 또는 삭제

제품 목록에서 제품을 선택해 수정하거나, 삭제를 눌러 제거합니다.

제품 선택 → 수정/삭제

SKU 주의

SKU는 제품 고유번호입니다. 같은 SKU로 저장하면 새 제품이 아니라 기존 제품 정보가 수정됩니다.

STOCK EDIT

본사 재고 수정

본사 관리자는 본사 재고의 현재 재고, 안전재고, 보관 위치를 수정합니다.

1

재고수정 열기

관리자 대시보드에서 재고 수정을 누릅니다.

재고 수정 클릭
2

제품 선택

수정할 제품을 검색하고 선택합니다.

제품 검색 → 제품 클릭
3

재고 입력

현재 재고, 안전재고, 보관 위치를 입력합니다.

현재 재고 → 안전재고 → 위치 입력
4

저장

재고 저장 버튼을 누릅니다.

재고 저장 클릭

STOCK VIEW

전체 재고 조회

본사는 본사 재고와 전체 대리점/샵 재고를 분리해서 조회합니다.

1

재고 메뉴 열기

재고 메뉴를 누릅니다.

재고 클릭
2

조회 범위 선택

본사 재고 또는 전체 대리점/샵 재고 탭을 선택합니다.

본사 재고 또는 전체 대리점/샵 재고 클릭
3

검색

제품명, SKU, 대리점명, 재고수량으로 검색합니다.

검색창 클릭 → 검색어 입력

안전재고 이하

현재 재고가 안전재고보다 적거나 같으면 강조 표시됩니다.

ORDERS

발주 확인과 상태 변경

본사는 전체 대리점/샵 발주를 확인하고 상태를 변경합니다.

1

발주 메뉴 열기

발주 메뉴를 누릅니다.

발주 클릭
2

발주 검색

주문번호, 제품명, SKU, 대리점명으로 발주를 찾습니다.

검색창 클릭 → 검색어 입력
3

상태 변경

발주 상태를 접수, 승인, 출고, 완료, 반려 중 하나로 변경합니다.

상태 선택 → 변경 확인

QR

QR과 카카오톡 안내문 전달

모든 대리점은 같은 QR과 같은 링크를 사용합니다. 로그인 정보만 대리점별로 다르게 전달합니다.

1

QR 메뉴 열기

QR 메뉴를 누릅니다.

QR 클릭
2

공통 QR 저장

QR 다운로드를 눌러 이미지를 저장합니다.

QR 다운로드 클릭
3

안내문 복사

대리점별 안내문을 복사해 카카오톡으로 전달합니다.

안내문 복사 → 카카오톡 붙여넣기

TROUBLE

사이트에 문제가 생겼을 때

본사 담당자는 먼저 전체 장애인지, 특정 사용자 문제인지 확인합니다.

1

문제 범위 확인

한 사람만 안 되는지, 전체 직원과 대리점이 모두 안 되는지 확인합니다.

다른 계정/다른 기기에서 접속 확인
2

화면 캡처 받기

문제가 생긴 사용자에게 오류 화면 캡처를 요청합니다.

오류 화면 캡처 요청
3

반복 작업 중지

저장이나 발주가 안 될 때 버튼을 여러 번 누르지 않도록 안내합니다.

반복 저장/반복 발주 중지 안내
4

기술 담당자에게 전달

발생 시간, 계정, 메뉴명, 증상, 화면 캡처를 정리해 전달합니다.

시간/계정/메뉴/증상/캡처 전달

즉시 전달할 상황

전체 접속 불가, 전체 로그인 불가, 샘플 모드 표시, 데이터 대량 삭제, 발주 중복 생성은 즉시 기술 담당자에게 전달합니다.

SHORTCUT

휴대폰 홈화면에 바로가기 만들기

운영 사이트를 휴대폰 홈화면에 추가하면 앱처럼 바로 열 수 있습니다.

아이폰 Safari

1

Safari로 사이트 열기

아이폰에서 Safari를 열고 GLOC 운영 사이트에 접속합니다.

Safari → 운영 사이트 접속
2

공유 버튼 누르기

화면 아래쪽의 공유 버튼을 누릅니다.

공유 버튼 클릭
3

홈 화면에 추가

홈 화면에 추가를 선택하고 이름을 확인한 뒤 추가를 누릅니다.

홈 화면에 추가 → 추가

안드로이드 Chrome

1

Chrome으로 사이트 열기

안드로이드에서 Chrome을 열고 GLOC 운영 사이트에 접속합니다.

Chrome → 운영 사이트 접속
2

더보기 메뉴 열기

오른쪽 위 점 3개 메뉴를 누릅니다.

점 3개 메뉴 클릭
3

홈 화면에 추가

홈 화면에 추가 또는 앱 설치를 선택하고 추가를 누릅니다.

홈 화면에 추가 또는 앱 설치 → 추가

아이콘이 바로 안 바뀔 때

예전에 만든 바로가기는 이전 아이콘이 남을 수 있습니다. 기존 바로가기를 삭제한 뒤 다시 추가하면 새 GLOC 아이콘으로 보입니다.

SHARE

본사 매뉴얼 공유하기

이 파일은 브라우저에서 열어 볼 수 있고, 필요하면 PDF로 저장할 수 있습니다.

1

브라우저로 열기

docs/manual-admin.html 파일을 더블클릭합니다.

2

PDF로 저장

인쇄 화면에서 대상을 PDF 저장으로 선택합니다.

인쇄 → PDF로 저장
